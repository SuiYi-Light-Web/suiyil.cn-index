本页基于[[fly.moe](https://github.com/fly3949/fly.moe "fly.moe")]修改，基于版本见分支[[origin](https://github.com/Suiyi-Light-Web/suiyil.cn/tree/origin "origin")]

## 部分使用说明
1.部分信息修改为XXX
2.WordPress文章接入请编辑 /assets/js/main.js `` var api = "/"; ``。
3.背景图片异步url在/assets/js/main.js，默认加载在 /assets/css/main.css  ``background-image: url("")`` base64 图片。
